From Bus Seats to Elderly Care: A Low-Cost Recycled Chair with COP-Based Posture Feedback

Authors: Eshaya Alisa, Saha Riti Proma, Sheikh Aimen Qaiser, Lau Hin Chung, Chiu Armstrong T. S.
Affiliation: Department of Biomedical Engineering, The Hong Kong Polytechnic University
Conference: Carnegie Mellon BME Forum 2026

Abstract

This project presents an upcycled, IoT-enabled smart chair for visually impaired elderly individuals, developed with the Hong Kong Society for the Blind and KMB. The chair repurposes transport-seating materials into a modular aluminum frame. Embedded sensors monitor Centre of Pressure (COP) shifts, providing real-time LED feedback for fall prevention. User testing confirmed stability and durability.

Author's Contribution

The author was responsible for the COP detection and display subsystem. This involved:

Designing and constructing four half-bridge strain gauge circuits for accurate COP measurement.
Integrating the strain gauges with the seat structure.
Implementing the LED matrix display to provide real-time visual feedback on posture and pressure shifts.
Design

Hardware: Upcycled modular frame, adjustable armrests and backrest.
Sensing: Four half-bridge strain gauges (author's contribution) for COP detection.
Feedback: LED matrix display (author's contribution) for posture and pressure cues.
Results

Strengths: Stable, durable, adjustable, real-time COP feedback.
Improvements: Too wide/tall, firm cushions, limited lower-back support, heavy.
Conclusion

The prototype delivers a working smart-seating system with sensor-based monitoring. The author's strain gauge and display subsystems functioned reliably. Next steps: adjust dimensions, improve ergonomics, reduce weight.

# From Bus Seats to Elderly Care: A Low-Cost Recycled Chair with COP-Based Posture Feedback

**Authors:** Peshaya Alisa, Saha Riti Proma, Sheikh Aimen Qaiser, Lau Hin Chung, Chiu Armstrong T. S.  
**Affiliation:** Department of Biomedical Engineering, The Hong Kong Polytechnic University  
**Conference:** Carnegie Mellon BME Forum 2026

## Abstract
This project presents an upcycled, IoT-enabled smart chair for visually impaired elderly individuals. Developed with the Hong Kong Society for the Blind and KMB, the chair repurposes transport-seating materials into a modular aluminum frame. Embedded load cells and strain gauges monitor Centre of Pressure (COP) shifts, providing real-time LED feedback for fall prevention. User testing confirmed stability and durability, while identifying needs for improved sizing, comfort, and portability.

## Design
- **Hardware:** Upcycled modular frame, adjustable armrests and backrest.
- **Software:** Load cells/strain gauges, LED matrix for posture feedback.

## Results
- **Strengths:** Stable, durable, adjustable, real-time COP feedback.
- **Improvements:** Too wide/tall, firm cushions, limited lower-back support, heavy.

## Conclusion
The prototype delivers a working smart-seating system with sensor-based monitoring. User testing validated stability and durability. Next steps: adjust dimensions, improve ergonomics, reduce weight.
